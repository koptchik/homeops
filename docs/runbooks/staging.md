# Deployment завершился ошибкой
- В GitHub Actions среди workflow runs находишь свой завершенный с ошибкой workflow переходя в него находишь job со статусом Failure, после открыть его и найти первый упавший шаг 

- Ошибки в ходе проверки проекта, при которых еще новая версия не дошла до staging:
    + Ruff - В коде есть ошибки формата, неиспользуемые импорты и неопределенные имена
    + Pytest - В тестовом контейнере получили ошибку в поведении
    + Pip-audit - В окружении имеются версии библиотек с известными уязвимостями или невозможность завершить аудит. Причину определяем по логам

- При ошибке deployment нужно обратить внимание на результаты и проверить статусы шагов восстановления, если rollback запускался:
    + Rollback staging 
    + Health check old container after Rollback

- Если rollback был пропущен, проверить, какой шаг упал. До переключения контейнера откат может не требоваться. После успешного health check новой версии ошибка cleanup также не должна запускать откат.

- Успешный rollback оставляет pipeline в ошибке так как новая версия не развернулась, хотя предыдущая версия восстановлена

- Ошибка rollback или его health check означает, что восстановление предыдущей версии не подтверждено и необходимо диагностировать staging

# Диагностика staging
Команды выполняются в Bash внутни staging LXC, где установлен Docker, а не внутри Docker-контейнера HomeOps.
- Вначале проверяем основной, временный и старый контейнеры, включая остановленные (-a)
```bash
docker ps -a --filter "name=homeops-staging"
```

- Затем проверяем  последние 100 строк логов
```bash
docker logs --tail 100 homeops-staging
```
> [!NOTE]
> если основного контейнера нет, надо посмотреть логи homeops-staging-old, если он присутствует

- Ссылка на образ основного контейнера - в нашем pipeline тег содержит SHA коммита
```bash
docker inspect homeops-staging --format '{{.Config.Image}}'
```

- Отвечает ли приложение на /health; --fail делает HTTP-ошибку неуспешным результатом команды
```bash
curl --fail --show-error http://127.0.0.1:8000/health
```
